# Privacy Policy

## Overview

`pet4agents` is a local-only desktop pet plugin for Claude Code and Codex CLI. It runs entirely on your machine and does not transmit any data to external servers.

## Data Collection and Storage

The plugin stores the following data locally on your filesystem:

### Configuration and State
- **User configuration** (`~/.config/pet4agents/config.json`) — your pet selection, animation speed overrides, and daemon behavior preferences
- **Window position** (`~/.config/pet4agents/state.json`) — the pet's last screen position
- **Session tracking** (in-memory only) — active Claude/Codex session IDs and process IDs, used to determine when to show/hide the pet

### Logs
- **Event log** (`~/.local/state/pet4agents/event.log`) — timestamped records of hook events (SessionStart, PreToolUse, Stop, etc.) and daemon state transitions
- **Install log** (`~/.local/state/pet4agents/install.log`) — Python venv setup output

Logs contain:
- Event names and timestamps
- Session IDs (random UUIDs generated by Claude/Codex)
- Process IDs
- Animation state transitions
- Error messages

Logs **do not** contain:
- Your prompts or conversations
- Code you're working on
- File paths or project details
- Any personally identifiable information beyond what's in the event metadata

### Runtime Data
- **Unix socket** (`${XDG_RUNTIME_DIR:-/tmp}/pet4agents.sock`) — inter-process communication between hooks and the daemon, cleared on daemon exit
- **PID file** (`~/.local/state/pet4agents/daemon.pid`) — tracks the running daemon process

## Data Sharing

**No data is transmitted to external servers.** The plugin:
- Does not make network requests
- Does not include analytics or telemetry
- Does not send crash reports
- Does not communicate with Anthropic or any third party

All processing happens locally. The only external dependency is PySide6/Qt, which is used solely for rendering the desktop widget.

## Data Retention

- **Configuration and state files** persist until you manually delete them or uninstall the plugin
- **Logs** are auto-truncated when they exceed `max_log_size` (default 5 MiB; set to `0` in config to disable); you can also safely truncate or delete them manually at any time
- **Session tracking** is in-memory only and cleared when the daemon exits

## Third-Party Dependencies

The plugin uses:
- **PySide6** (Qt for Python) — GUI framework, no telemetry
- **Python standard library** — no external data transmission

## Your Control

You can:
- View all stored data in the paths listed above
- Delete logs, config, or state files at any time without breaking the plugin (defaults will be used)
- Uninstall the plugin completely (see README.md) to remove all traces

## Questions

This plugin is open source. If you have privacy concerns, you can inspect the code in `scripts/pet_daemon.py`, `scripts/pet_event.py`, and `scripts/config.py`.

For issues or questions, see the repository's issue tracker.
